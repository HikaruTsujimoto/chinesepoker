# このPCのアカウントと成績

## テストアカウントで遊ぶ

1. 起動時に「テスト1」「テスト2」「テスト3」のいずれかを選びます。
2. メニューの「Play vs CPU」で開始します。2人対戦ではPlayer 2にも別のアカウントを選びます。
3. 「成績を見る」でCPU対戦・2人対戦の記録を確認できます。

3つのアカウントは初回に自動作成します。再起動で成績や残高はリセットしません。
既存アカウントも引き続き選択できます。このテスト版では新規名前入力・ゲスト開始は表示しません。

## 終了条件とコイン

- 開始時の対局得点は0点。累計+100点または−100点に到達すると終了待ちになります。
- その時点でFL権がある場合は継続し、両者の次回FL権がなくなったハンドで終了します。
- 一度終了待ちになると、FL中に得点が100点未満へ戻っても終了待ちを維持します。
- FL終了時の最終累計得点が正なら勝ち、負なら負け、0なら引分です。
- 勝ちは+100コイン、負けは−100コイン、引分は増減なし。ハンドごとには増減しません。
- 初期残高は1,000コイン。既存アカウントにも初回だけ1,000コインを設定します。
- 選択したアカウントに1日1回50コインを自動付与します。日本時間の午前0時で日付を区切ります。
- 初日のデイリーも対象なので、初めて選んだ後の残高は1,050コインです。未ログイン日の遡及付与はありません。
- 再起動時は選択済みアカウントの当日分を確認します。同日中に選び直しても追加付与しません。
- 開始には各アカウント100コイン以上が必要です。コインはこのPC内のゲーム用数値です。

得点とコインは別の数値です。例えば最終+123点でも獲得コインは100です。
対局終了画面の「メニューへ」で戻れます。次の対局は0点から始まります。
途中終了した対局は精算せず、終了済みハンドだけ記録します。中断対局の再開には対応しません。
このローカルテスト版はPCの日付を利用します。オンライン認証や不正対策はありません。
同じアカウントで複数のアプリを同時に遊ぶと、それぞれの敗北で減算され残高が負になる場合があります。

## 数字の意味

| 項目 | 集計方法 |
|---|---|
| 完了対局 | 累計±100点到達後、両者の次回FL権がなくなるまでを1対局 |
| 対局の勝・敗・分 | その対局の実得点合計が正・負・0 |
| 対局の勝率 | 勝った対局数 ÷ 引分を含む完了対局数 |
| 完了対局の累計得点 | 最後まで終わった対局の得点合計 |
| 完了ハンド・ハンドの勝敗 | 13枚の配置と得点精算が完了した各ハンドを集計 |
| 全完了ハンドの累計得点 | 途中で終了した対局に含まれる終了済みハンドも含めた合計 |
| FL新規進入・進入率 | 通常から次のFL権を得た回数 ÷ 通常状態で終了したハンド数 |
| FL継続・継続率 | FLから次のFL権を維持した回数 ÷ FL状態で終了したハンド数 |
| 新規FLの内訳 | 14・15・16・17枚の新規進入回数。継続は含めない |
| ファウル率 | ファウルしたハンド数 ÷ 全完了ハンド数 |

分母が0の率は「—」です。最近5ハンドの得点とFL進入・継続・終了も表示します。
CPU対戦と2人対戦は別集計です。FL進入の権利を得た後にアプリを閉じた場合も、進入を達成したハンドは記録されます。

未完了ハンドを閉じても、そのハンドは集計しません。途中終了した対局を勝ち・負けとみなすこともありません。
この機能は成績の保存であり、中断した対局を再開する機能ではありません。

## 保存先

Windowsでは `%LOCALAPPDATA%\ChinesePoker\profiles.sqlite3` に保存します。
exeの場所とは独立しているため、同じWindowsユーザーでexeを更新・移動しても成績を引き継ぎます。
アプリをすべて終了した状態で、このファイルをコピーするとバックアップできます。
通信、メールアドレス、パスワードは不要です。このPC内の名前付きプロフィールです。

保存に失敗した場合は結果画面に表示し、Rキーで再試行できます。成功するまでは次のハンド・メニュー移動を止めます。
再試行による二重計上はありません。保存失敗中にアプリを閉じると、その未保存ハンドは失われます。
保存データを開けない場合はアカウントを選べないため開始できません。

## 開発時の検証

`CHINESEPOKER_DATA_DIR` で保存フォルダーを変更できます。テストは一時DBを使い、実アカウントへ書き込みません。

```powershell
python -m unittest discover -v
python -m chinesepoker --profile-smoke-test
```

スモークテストは一時アカウント作成・画面描画・別プロセスCPUとの1ハンド・成績保存・DB再読込を検証します。
各ハンドは両プレイヤー分をSQLiteの同一トランザクションで保存し、ハンドIDで二重記録を防止します。

旧版の成績は保持します。旧版の「FLが終わるまでを1対局」という集計も履歴に残りますが、過去の対局へのコイン付与は行いません。
