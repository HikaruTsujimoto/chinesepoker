# 実戦用Hybrid CPU

起動後に **CPU - Hybrid (test)** を選びます。旧CPUは **CPU - Normal** で引き続き使えます。
学習済み重みは `chinesepoker/ai/session_value.json` とexe内に同梱されます。
外部サービスや追加ライブラリは不要です。`--strategy` は従来の単一ハンドMCCFR用で、
このモデルの指定には使いません。

## 局面を一般化する学習

カードの完全一致を調べるMCCFRテーブルとは別に、74個の数値特徴を使う正則化線形モデルを追加しました。
各段の空き枠、ペア・スリーカード・フォーカード、同一スート枚数、連続ランク、
上段の高いペア、役の逆転、公開された相手の盤面を特徴にします。
スート名を一括で入れ替えても同じ予測になるため、未経験の配札にも適用できます。
非公開の相手カードや山札は推論に渡しません。捨て札や全履歴までは特徴に含めない、粗い近似です。

教師データは自己対戦で発生した通常手の配置直後の局面です。
教師値は **現在のハンド開始から、両者のFL権が消えるまでの残り累計実得点** です。
FL継続中の途中打切りを終局として採点しません。資源上限で打ち切られた対局があれば
モデルの保存を中止し、長いFLを除外した偏りが入るのを防ぎます。
教師方策はEasyベースに15%のランダム通常手を加え、FLには新探索を使っています。
強い方策の最適価値を学んだものではありません。

実戦では、予測値を±20点に制限して0.4倍し、既存の盤面評価に加えます。
それによって通常手の探索候補を選び、その後は従来同様のロールアウトで手を決めます。
修復不能なファウルの扱いと、最終手の全合法手評価は維持します。
予測値だけで着手を決める方式ではありません。

## FL探索の変更

旧探索は強いボトムから順にミドルとの組合せを深く調べるため、時間切れまでに
最初のボトム付近しか探索できないことがありました。新探索はボトム候補を役の種類で
交互に選び、各ボトムにミドル候補を1つずつ割り当てて巡回します。
余りのカードからトップを列挙し、通常の役判定・ロイヤリティ・継続条件で評価します。
現在のFL枚数を継続時も維持します。

この実戦用探索はMCCFRの「ランダム抽出した16候補」には制限されません。
一方、全配置を必ず調べる方式でもありません。時間内に得た最良配置を返します。
FLの将来価値には引き続き既存の定数近似を使います。新学習モデルがFL配置の長期価値を
直接解いているわけではありません。

## 再学習と比較

今回の配布モデルは5,000セッション（5,665ハンド、53,250局面）で学習しました。
別の1,000セッション（1,147ハンド、10,730局面）での平均二乗誤差は282.640、
学習データの平均値を常に予測する基準は329.732です。誤差は約14.3%減少しました。
これは予測精度の検証であり、対戦勝率や均衡への近さを表す数値ではありません。

リポジトリのルートで実行します。

```powershell
python -m tools.train_value --sessions 5000 --validation 1000
python -m tools.evaluate_hybrid --pairs 16 --seed 20310000 --seconds 1.5 --variants hybrid
python -m tools.evaluate_hybrid --pairs 12 --seed 20320000 --seconds 1.5 --variants fantasy --initial-tiers 14 17 --output docs/hybrid-fl-evaluation.json
python -m unittest discover -q
python -m chinesepoker --cpu-smoke-test --cpu-level hybrid
python tools/build.py
```

評価は旧Normalに対して席を交換し、FLが双方終了するまで対局します。
同じペア内では同じ山札乱数を使いますが、FL進入の違いで後続の配牌は分岐します。
学習用・予測検証用・対戦評価用の配牌シード範囲は分離します。
主指標は対局全体の平均得点差です。対局ペアを単位に近似95%区間を計算し、
ファウル率と実際の判断時間も保存します。打切りがあれば平均得点を出しません。
時間制限によって探索量が変わるため、同じseedでも異なるマシンで完全一致はしません。

短時間の比較 `hybrid-screening.json` は400セッション版の探索的な予備実験です。
その重みは `value-model-pilot.json` に保存し、配布モデルとは区別しています。
学習モデル単独・FL探索単独・両方の3条件を比較していますが、複数比較の補正はしていません。

## 対戦評価（2026-10-18）

配布モデルの通常開始・16ペア32対局は、39ハンドですべて自然終了しました。
Hybridの対旧Normalの平均得点は **+0.46875点/対局**、ペア単位の近似95%区間は
**[-2.23461, +3.17211]** でした。新旧のファウル率はそれぞれ10.26%・7.69%、
平均判断時間は0.383秒・0.386秒（双方の上限目安1.5秒）、FLプレイヤーハンドは7です。
生データは `hybrid-evaluation.json` に保存しています。

**この比較では強化を確認できていません。** 予測誤差の改善を対戦強度の改善と混同せず、
Hybridは実験用の選択肢として提供します。少ない対局の結果から旧Normalの全面置換は決めません。

FL探索だけを差し替えた14枚FL対17枚FL開始の12ペア24対局は、82ハンドで自然終了しました。
平均得点差は **+14.16667点/対局**、近似95%区間は **[+0.48610, +27.84723]** です。
FLプレイヤーハンドは109、新旧のファウル率は4.88%・6.10%、平均判断時間は0.819秒・0.689秒でした。
双方の時間上限設定は1.5秒です。生データは `hybrid-fl-evaluation.json` に保存しています。
この比較では通常手の方策を同じにして、FL探索だけの違いを見ています。
限られたFL開始条件では改善の兆候がありますが、区間は広く、通常開始の全体的な強化や
すべてのFL枚数・相手に対する優位性を保証しません。複数の比較に対する補正はしていません。

全55件の自動テストが成功しました。モデルを同梱したWindows exeをソースの外のディレクトリから
起動し、実際の子プロセスでHybridが学習モデルを使用して1ハンドを完了することも確認しました。

## 均衡学習との関係

これは未経験局面でも動く実戦用の補助価値学習です。MCCFRの後悔値をニューラルネットに
移植したものではなく、ナッシュ均衡の証明もありません。従来のMCCFR学習器・
全ゲームの終局条件・厳密小規模評価は独立に残しています。
より強くするには教師方策の更新、通常・FL双方の継続価値学習、より大きな独立評価が必要です。
